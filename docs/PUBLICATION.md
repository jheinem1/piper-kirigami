# Repository publication policy

The README must retain its ACTIVE DEVELOPMENT notice. Issues and pull requests are closed to submissions at this stage; this is not an additional restriction on the free-software licenses.

The repository administrator should disable both features under Settings → General → Features and verify the resulting settings. GitHub added configurable pull-request access in February 2026, including disabling pull requests entirely. See the official [PR disabling documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/enabling-features-for-your-repository/disabling-pull-requests) and [announcement](https://github.blog/changelog/2026-02-13-new-repository-settings-for-configuring-pull-request-access/). Do not substitute an automatic PR-closing bot or archive the development repository merely to implement this policy.

Configuration is an administrator action; the presence of this file does not prove that the remote settings have been changed.
